
# 1. Project Name: Peddy - Pet Adoption Platform

## 2. Short Description of this Project
Pet Peddy is a pet adoption website where users can view different kinds of pets, see their details in a modal, and adopt pets according to their preferences. The site offers a sorting option where users can sort pets by price in descending order. Additionally, the website will save the activity when a user clicks the "Like" button.

## 3. Significant Five Key Features of the Projects

- **Pet Browsing By Categories:** Users can easily explore pets by filtering them according to their preferred categories.

- **Detailed View:** When the user clicks the "Details" button, a modal opens, allowing more details about  a specific pet.

- **Sort By price:** This Feature allows users to organize pet data in descending order based on Price.

- **Activity History:** This functionality saves user interactions, allowing users to quickly find pets they have recently viewed on the website

- **Responsive Friendly:** The website's responsive design ensures a better viewing experience for users.

## 4. Some ES6 Features Implementation  

- ***Arrow Function:*** It makes the code easier to read and write by providing a concise syntax for defining functions.
- ***Template Literals:*** Users can easily use data from APIs or other objects and dynamically insert them into strings.
- ***Destructuring data:*** A popular approach for extracting values from arrays or properties from objects and assigning them to individual variables.
- ***Default Parameter:*** Default parameters allow users to set a default value for a function's parameter. It helps prevent errors and ensures that the function default behaves  when no argument is provided
- ***variable: let const:*** "var is function-scoped and hoisted. In ES6, let allows reassignment of values, while const does not allow reassignment, ensuring immutability
- ***Spread Operator:*** A method to create a new array that does not affect the original array.
